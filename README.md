# Leucoteo — anteprima

Prototipo statico della piattaforma che mette in contatto creator e aziende
e segue una collaborazione dall'accordo alla conclusione.

**È solo il frontend**: non c'è nessun backend, i dati sono di esempio e
nessuna informazione viene salvata o inviata da nessuna parte.

## Cosa si può girare

| | |
|---|---|
| [`index.html`](index.html) | la presentazione |
| [`entra.html`](entra.html) | l'iscrizione, dai due lati |
| [`accedi.html`](accedi.html) | l'accesso |
| `app.html?lato=creator` | il prodotto, lato creator |
| `app.html?lato=azienda` | il prodotto, lato azienda |
| [`mediakit.html`](mediakit.html) | il profilo pubblico di un creator |
| [`termini.html`](termini.html) | cosa si vede e cosa no |

Da «Accedi» si entra nella dimostrazione scegliendo il lato.
